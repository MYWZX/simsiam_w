## 三个重点说明

1. **L2是直接对特征数值做的算术运算**，没有可训练权重，不是一个新的神经网络。对一个向量x计算 x/max(sqrt(sum(x²)),epsilon)，形状不变。例[3,4]→[0.6,0.8]。模型对每个768维/256维特征向量的通道轴归一化，不跨图像归一化。该运算可微，仍可向前面的可训练模块传播梯度。零/极小向量使用epsilon保护。
2. **P₀不是正方体**。ResNet输出先是H×W×C特征图；14×14×256展平为196×256矩阵，196行对应空间位置、256列对应通道。数值总量始终是50,176，不做池化或平均；批量形状为B×196×256。立体图标只是特征图的长方体示意，几何比例不代表真实维数。示意矩阵的网格行列也不是按196/256格逐一绘制。
3. **两个独立1×1投影是可学习卷积层**。在每个空间位置，将该位置的通道向量做 y=W x+b。第一层1024→256，权重形状[256,1024,1,1]；第二层256→256，权重[256,256,1,1]；两层各自有不同参数。每一层在所有空间位置复用该层参数，空间大小14×14不变。它们不直接混合相邻位置，已有ResNet负责此前的空间特征提取。源码对应local_encoder.proj和local_patch_proj，原结构完整保留。

## 路径与形状

- 单张输入示意224×224×3为HWC写法；PyTorch批量输入实际[B,3,224,224]。
- CLIP ViT-L/14：16×16个patch + CLS，内部[257,1024]；取CLS经CLIP自带1024→768投影输出全局768维向量。项目L2后经semantic_proj Linear768→256得g。
- 当前P₀来自另一条ResNet-50 layer3分支，**不是CLIP内部256个patch token**。ResNet layer3 [B,1024,14,14]，两个独立1×1卷积后[B,256,14,14]，flatten(2).transpose(1,2)→[B,196,256]。
- 全局g直接进入QAM；另经PI得到256维v供AAM和I-I。P₀绕过PI。NSS n为196×6。
- 文本Encoder的P/A是同一组参数的分别调用；5个上下文词元可训练，文本塔原权重冻结。768维输出经L2、T768→256、PT+L2得到256维表示。
- 总图右侧AAM只接收Prompt对应的t。Answer只参与预训练关系，不能误读为下游额外输入。Prompt的SRM表示还经过AT/W_T，详见AAM/TPM/SRM细图。
- QAM最终输出质量标量S_Q；AAM结合Prompt输出独立的一致性标量S_A。最终评分路径没有跨注意力与融合z。
- 当前最好基线的CLIP图像编码器可训练。冻结CLIP实验仅更改其训练状态，形状不变；semantic_proj等投影仍可训练。新图没有改变训练代码或实验定义。

## 线型与复用

实线箭头为数据流，分叉圆点表示同一特征复用。没有圆点的跨线通过断口区分，不是连接。模块页的灰色点线为训练监督。shared weights表示复用参数；reuse表示复用特征，不是新建网络。sg表示停止该路径梯度，与永久冻结不同；锁只表示实际冻结的文本塔原权重。

总图下方只概括预训练附加关系/人工监督；完整四个SRM输入配对见第6页。质量文本五档CE关闭；Component Anchors/Ordinal仍启用。图中输入缩略图、张量及热图均为示意，不代表实际实验样本或测量结果。

## 复现与检查

安装requirements.txt、系统LibreOffice，运行 `python generate_all.py --output-dir ./rendered`。同目录generate_srm.py、drawing_primitives.py和fonts/为依赖；字体与许可证随包。

公式主要为可编辑原生文本分组，并非Office公式编辑器对象。主要对象已分组/命名；连线为原生连接器。7页已实际渲染检查；PDF无栅格化对象、无替换字符及页外文字；PPT对象ID唯一、连接引用有效；PNG逐像素匹配同源PDF渲染。source_audit.json记录相关源码版本，render_audit.json记录各页尺寸及对象数。
