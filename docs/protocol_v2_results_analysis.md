## 按验证指标选择，而非测试挑选

在三个数据集都有完整结果的 baseline、proj_lr 之间，用三数据集验证质量 SR 等权平均作共同配置的比较。该规则在文档中曾作为共同规则示例，此处作为明确比较依据，不声称它已预注册。

- baseline：平均验证 Q SR = 0.876263192。
- proj_lr：平均验证 Q SR = 0.873957024。

- proj_lr 相比 baseline：1K 验证 SR +.000476、3K +.001039，2023 −.008434，尚不支持作为三个数据集统一改进；1K/3K 的验证优势也很小，单种子不足以确认稳定收益。
- align_aux：3K 验证 SR −.000645，2023 −.003795。2023 的验证 Align SR 从 .784422 到 .792703，存在质量/一致性取舍，不能说所有维度都无用。
- 1K qa_bn 的验证质量 SR 最高 .897501（baseline .893586），但测试 Q PL 为 .877104（baseline .879750）。验证改善没有转化成所有测试指标改善；其余数据集未跑，不能称为共同配置最优。
- 1K resnet_bn 的验证质量 SR 降到 .887850，不建议根据这次结果推广。

共同方案建议保留 baseline，进入此前已规划的 80/20 固定预算重训，先不叠加这些控制。若专门研究 QA BN 冻结，需要另补 3K/2023 的验证结果，而不是直接把 1K 结果套用。

## 泛化情况

训练指标来自 train() 模式、训练过程中在线累计，并非最终模型对全训练集的独立 eval；只能作为泛化差距线索。

| baseline 数据集 | 选中轮在线训练 Q PL | 验证 Q PL | 测试 Q PL |
|---|---:|---:|---:|
| agiqa1k | 0.984008 | 0.894117 | 0.879750 |
| agiqa3k | 0.996816 | 0.929365 | 0.932850 |
| aigciqa2023 | 0.996302 | 0.875873 | 0.885429 |

三个数据集仍存在训练与验证表现差距。2023 差距尤其明显；QA/ResNet 冻结或降低 PI/PT 学习率，没有提供跨数据集一致的改善证据。这些数据不能证明过拟合已解决，也不能单独区分训练过拟合、划分差异与标注噪声。3K baseline 的最佳验证 SR 位于第 60 轮预算边界，不能断言已收敛；此处仍遵守现有 60 轮预算，不因测试结果临时延长。
